# Originals Protocol specification

[Read the VH-based Editor’s Draft 0.1](SPEC.md).

This repository preserves the original first review draft dated 8 October 2026. It is a protocol and SDK design for review, not a finalized standard or an implementation.

The draft contains 12 sections, a 25-test conformance matrix, and seven open decisions. Proposed rules and unresolved questions remain as written in the original draft. Active CEL history is replaced with Verifiable History while useful SDK semantics are retained.
